### What changed
- BUG-0014 fixed: `SimRng` runs the seed through `MixSeed` (SplitMix64's output function, a
  bijection) before PCG seeding, so seed `ulong.MaxValue` and seed 0 no longer give the same map.
  Every pinned map hash moved once (15 in `MapGeneratorTests`); six tests calibrated on one old map
  keep their old map through `TestSeeds.PreMix` (the inverse of `MixSeed`).
- `Rts.Sim.Replays` (namespace, not `.Replay`, to avoid a type/namespace clash): `Replay` (header,
  command log, checkpoints, `Validate`), `ReplayRecorder` (attached to a fresh sim; records every
  accepted command as stamped and `StateHash()` every 100 ticks, inside `Tick` phase 14, from a
  preallocated buffer), `ReplayFormat` (ASCII, LF, canonical numbers, floats as IEEE bit patterns,
  FNV-1a checksum line; `TryRead` never throws), `ReplayPlayer.Run` (refuses on format version or
  data hash before any tick, feeds commands at `Tick - 1`, checks re-stamped sequence numbers,
  stops at the first checkpoint mismatch), `ReplayError` codes (no prose in C#).
- `GameData.ContentHash()` over every field of every def (strings char by char, incl. display text).
- Golden `sim/Rts.Sim.Tests/Replays/cross_map_seed1.replay` (15,526 bytes): seed-1 cross-map march,
  200 units, 1,500 ticks, 15 checkpoints. `RTS_REGEN_GOLDEN=1` rewrites it and fails.
- `Simulation.Enqueue`/`Tick` gained one `_recorder?.` call each; `World.HasGeneratedMap`
  (hand-made test maps can't be replayed). Public setup API stayed additive.
- docs/03: phase 14, Determinism (seed mixing), Save/load and replays (format), Testing strategy.
- ~3,450 lines changed: ~860 production, ~1,000 dev tests, ~1,000 QA tests, golden 444 lines, docs.
