# QA reports

One report per inspection, written by the QA inspector:
`<SESSION_ID>-<TASK_ID>.md` for studio sessions, `<SESSION_ID>.md` for ad-hoc `/qa` runs.
The report uses the format defined in `.claude/agents/qa-inspector.md` (verdict, baseline,
independently verified criteria, findings, stress results, tests added).

[coverage.md](coverage.md) is the running map of which systems have which kinds of tests.
