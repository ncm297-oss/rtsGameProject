Observations, not filed:
- Rebuild cost scales with the bucket count, not the unit count. A 1024 x 1024 map (legal, not the design size) takes 0.65 ms for 2,500 units and 0.88 ms for 12,500, mostly clearing and prefix-summing 262k buckets. That is above the 0.5 ms figure if it were applied to the max map; fine for the 128-cell design map.
- Deathball worst case: 2,500 units in one bucket make 500 radius-8 queries cost 8.1 ms, mostly sorting. Nearest-enemy for the same layout costs 3.1 ms. An infinite-radius query on a 1024 map costs 0.6 ms.
